GitHub Token

Token digunakan untuk push perubahan ke GitHub. Token disimpan di browser ini saja (localStorage).

Belum ada token
Cara mendapatkan token:
  1. Buka github.com/settings/tokens
  2. Klik "Generate new token (classic)"
  3. Beri nama: admin-atapbaja
  4. Centang scope: repo
  5. Klik Generate, lalu copy token (ghp_xxxxx)
  6. Tempel token di atas, klik Simpan
